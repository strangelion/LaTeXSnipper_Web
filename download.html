安装说明

Windows 安装提示

下载完成后双击运行安装程序。如果 Windows SmartScreen 弹出安全提示，请选择"仍然运行"。 安装程序需要管理员权限，安装过程中可以选择安装目录和创建桌面快捷方式。

macOS 安装提示

下载 DMG 文件后双击打开，将应用图标拖入"应用程序"文件夹。 首次打开时 macOS 可能提示"无法验证开发者"，请在"系统设置 → 隐私与安全性"中允许运行。 当前版本仅支持 Apple Silicon；Intel Mac 当前没有兼容安装包。

如何验证文件完整性

下载完成后可以使用页面提供的 SHA256 与本地计算结果进行比较。 Windows 用户可在 PowerShell 中运行 Get-FileHash 文件路径 -Algorithm SHA256， macOS/Linux 用户可运行 sha256sum 文件路径 或 shasum -a 256 文件路径。
