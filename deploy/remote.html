    连接这台电脑 在桌面端开启「远程设备」，再把地址和密钥填到这里
    图片不经过本站
    上传直接指向你填写的桌面地址。本站服务器看不到、也存不下任何图片。
    仍然使用桌面版的模型
    公式、文字、混合排版与整页检测都由你电脑上已配置的识别后端处理。
    需要你显式授权
    桌面端默认拒绝一切远程访问。只有你开启远程设备、生成密钥并放行本页地址后才能连接。

    在电脑上开启「远程设备」

    这一步必须在桌面版里完成。手机或平板无法代你开启。

    1. 打开 LaTeXSnipper 桌面版，进入 设置，找到 自动化接口。
    2. 把 访问范围 从「仅本机」改为 「远程设备」。
    3. 把 安全方式 选为 「安全隧道（推荐）」。这表示你已经在 Tailscale、WireGuard 之类的加密隧道里，浏览器将用 http 直连设备地址。
    4. 在 监听地址 里填写这台电脑在隧道里的 IPv4 地址，例如 100.101.102.103。端口保持默认的 28765。

      必须填 IP 地址，不能填 machine.tailnet.ts.net 这类域名：桌面端只接受与监听地址完全一致的 Host 头，浏览器无法改写它。

    5. 点 「重新生成访问密钥」，再点 「复制访问密钥」。这个密钥只属于远程设备，不要和本机凭据混用。
    6. 在 「浏览器 Origin 白名单」 里粘贴这一步下面显示的地址（本页的 Origin），多个地址用英文逗号分隔。
      …
    7. 勾选 「我已了解远程设备可向本机提交图片，并确认连接方式安全」，然后点 保存。

    需要识别时桌面版要保持运行。远程设备默认只能调用公式识别后端，不会使用你已配置的外部模型，除非你在桌面端另行开启。

    在本页填写连接信息

    填写你刚才在桌面端配置的地址和密钥，然后测试一次连接。

    与桌面端「监听地址」和「端口」拼起来，形如 http://<隧道IP>:28765。不要带路径。

    只保存在这台设备的浏览器里，用于向你的电脑证明身份。

    连不上时按顺序检查 七种常见报错分别对应什么原因

    浏览器提示「无法访问本地网络」或请求被拦截

    这是 Chrome 142 起对「网页访问本地地址」的权限门控。点击地址栏提示里的允许，或在站点设置里为本站开启「本地网络访问」，然后重试。桌面 Safari 与 iOS 尚未确认是否支持该项授权，若被拦截请改用桌面版或系统快捷指令。

    请求返回 403 forbidden，消息是「该 Origin 不在允许列表中」

    本页地址没有写进桌面端的「浏览器 Origin 白名单」。展开上面的「连接这台电脑」，把那里显示的地址复制过去，一个字都不要改。

    请求返回 400 invalid_request

    桌面端收到的 Host 与你填写的地址不一致。确认地址用的是隧道 IP，且与桌面端「监听地址」完全相同。

    请求返回 401 unauthorized

    密钥不对，或桌面端保存后接口还没重启。重新复制一次访问密钥。

    浏览器报「混合内容」被阻止

    你填的是 http 地址，而本页是 https。较新的 Chrome 会在你授权本地网络访问后放行；如果仍被阻止，说明该浏览器版本不支持这项放宽，请改用 https 隧道地址或系统快捷指令。

    请求一直挂起或超时

    设备不在同一隧道内，或隧道未启动。先在手机上用浏览器直接打开你填写的地址，确认能看到桌面端的响应。

    返回 503 backend_unavailable 或 model_unavailable

    桌面端的识别模型尚未加载完成，或所选后端当前不可用。

    说明：本页只是浏览器端的连接客户端，所有识别都在你授权的桌面版上完成，本站不参与、也无法看到传输内容。地址与密钥保存在本机浏览器的 localStorage 中，请勿在公用设备上勾选「记住」。远程凭据默认只能使用公式识别后端，也不会返回桌面端的结果流。
